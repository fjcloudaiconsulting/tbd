# Security Policy

## Reporting a vulnerability

Report suspected vulnerabilities privately to **flamarion@fjconsulting.io**.
Please do not open a public issue for a security problem.

Include what you can: the affected endpoint or component, the steps to
reproduce, and the impact you believe it has. A first response should arrive
within five working days.

## Scope

This repository holds the application source. Reports about the hosted
service at `app.thebetterdecision.com` are in scope. Findings that require a
pre-existing superadmin session, or physical access to the data plane, are
out of scope.

## Supported versions

Only `main` is supported. There are no maintained release branches.
